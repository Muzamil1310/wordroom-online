Common questions

What is Base64 encoding?

Base64 encodes binary data as ASCII text using 64 characters: A-Z, a-z, 0-9, + and /. It is commonly used to embed images in HTML/CSS, transmit data in JSON and encode credentials in HTTP headers. The encoded output is roughly 33% larger than the original.

Is Base64 the same as encryption?

No. Base64 is an encoding, not encryption. Anyone can decode it without a key. It is used for data transport, not security. If you need to protect data, encrypt it before encoding.

Does it handle Unicode correctly?

Yes. The tool first encodes the input as UTF-8, then applies Base64 encoding. This means characters like emoji, accented letters and CJK scripts are encoded correctly. Decoding reverses the process and restores the original text.
