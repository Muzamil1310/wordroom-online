Zeilen sortieren

Alphabetisieren, nach Länge sortieren, umkehren oder mischen — mit natürlicher Zahlenreihenfolge und sprachgerechter Sortierung.

Alphabetisch ist nicht eine einzige Sache

Sortieren sieht wie ein gelöstes Problem aus, bis Sie echte Daten sortieren. Ein naiver Sort vergleicht Codepoints, die jeden Großbuchstaben vor jeden Kleinbuchstaben setzen — also wird „Zebra" vor „apple" sortiert und eine Liste von Namen kommt in einer Reihenfolge heraus, die kein Mensch alphabetisch nennen würde.

Dieses Tool verwendet stattdessen sprachbewusste Sortierung, dieselbe Mechanik, die Ihr Betriebssystem verwendet, um eine Dateiliste zu sortieren. Akzentuierte Zeichen werden neben ihren Grundbuchstaben sortiert, nicht am Ende, und Groß-/Kleinschreibung wird standardmäßig ignoriert, weil das ist, was Menschen mit alphabetisch meinen.

Natürliche Zahlenreihenfolge ist die andere häufige Überraschung. Als Text verglichen wird „Element 10" vor „Element 2" sortiert, weil „1" weniger als „2" ist. Natürliche Ordnung vergleicht die Zahlenabschnitte als Zahlen, was Element 1, Element 2, Element 10 ergibt. Lassen Sie es für alles mit Zahlen aktiviert.

Sortiermodi

  • Alphabetisch — sprachbewusst, standardmäßig fallunabhängig. Schalten Sie Absteigend für Z bis A ein.
  • Nach Zeilenlänge — kürzeste zuerst, Gleichstand alphabetisch aufgelöst. Nützlich zum Erkennen von Ausreißern in einer Liste von Schlüsselwörtern oder Überschriften.
  • Aktuelle Reihenfolge umkehren — dreht die Liste ohne sie zu sortieren, was Sie normalerweise für ein chronologisches Protokoll wollen.
  • Mischen — ein Fisher–Yates-Mischen, also ist jede Reihenfolge gleich wahrscheinlich. Naive Mischungen mit einem Zufallsvergleich sind verzerrt.

Leerzeilen werden standardmäßig entfernt, da eine sortierte Liste mit einem Block Leerzeilen am einen Ende selten das ist, was jemand will. Schalten Sie es aus, wenn Leerzeilen Bedeutung tragen.

Häufige Fragen

Warum wurde meine Liste mit Großbuchstaben zuerst sortiert?

Das passiert mit Tools, die rote Zeichencodes vergleichen, bei denen jeder Großbuchstabe jedem Kleinbuchstaben vorangestellt ist. Dieses Tool verwendet sprachgerechte Sortierung und ignoriert Groß-/Kleinschreibung standardmäßig, sodass Sie die Reihenfolge erhalten, die eine Person erwarten würde. Schalten Sie Groß-/Kleinschreibung beachten ein, wenn Sie die strikte Version benötigen.

Warum kommt Element 10 vor Element 2?

Als Text verglichen ist "1" kleiner als "2", daher wird "Element 10" zuerst sortiert. Schalten Sie Natürliche Zahlenreihenfolge ein, um die Zahlenabschnitte als Zahlen zu vergleichen, was Element 1, Element 2, Element 10 ergibt. Es ist standardmäßig aktiviert.

Ist die Vermischung wirklich zufällig?

Es verwendet eine Fisher-Yates-Mischung, bei der jede mögliche Reihenfolge gleich wahrscheinlich ist. Mischen durch Übergeben eines Zufallsvergleichs an eine Sortierfunktion ist ein gängiger Kurzweg und erzeugt messbar verzerrte Ergebnisse.
