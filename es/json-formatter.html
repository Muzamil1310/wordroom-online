Preguntas frecuentes

¿Qué hace el formateo bonito?

El formateo bonito añade sangría, saltos de línea y espaciado para hacer JSON legible para humanos. JSON minificado como {"a":1,"b":[2,3]} se formatea con sangría anidada, facilitando la comprensión de la estructura.

¿Qué pasa si mi JSON es inválido?

La herramienta muestra un mensaje de error claro con la línea y posición donde se encontró el error de sintaxis. A diferencia de muchos formateadores online, no arregla ni altera silenciosamente tu JSON — te dice exactamente qué está mal.

¿Puedo ajustar la sangría?

Sí. Puedes elegir entre 2 espacios, 4 espacios o sangría con tabulaciones. La salida formateada se actualiza instantáneamente cuando cambias la configuración.
