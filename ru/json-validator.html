Частые вопросы

What does valid JSON mean?

Valid JSON follows the JSON syntax rules: strings use double quotes, objects and arrays are correctly structured, and values use valid JSON types such as strings, numbers, booleans and null.

Can a JSON value be just a number or true?

Yes. A JSON document can have a primitive root value such as <code>123</code>, <code>true</code>, <code>false</code> or <code>null</code>, as well as an object or array.

Why is my JSON invalid?

Common causes include single quotes, missing commas or brackets, trailing commas, unquoted keys and comments. JSON is stricter than JavaScript object-literal syntax.

Is validation performed locally?

Yes. The validator uses the browser's built-in JSON parser, so the JSON you enter is processed locally.
