О WordRoom

Что мы создали

WordRoom — это коллекция бесплатных текстовых инструментов с приоритетом конфиденциальности, которые работают полностью в вашем браузере. Мы начали с простого наблюдения: большинство онлайн-текстовых инструментов загружают ваш контент на сервер, хотя в этом нет необходимости.

Каждый инструмент WordRoom обрабатывает ваш текст локально с помощью JavaScript. Ничего из того, что вы печатаете или вставляете, никогда не отправляется куда-либо. ваша работа остаётся на вашем устройстве.

Почему важна конфиденциальность

Когда вы вставляете черновик, коммерческое предложение или личные заметки в онлайн-инструмент, вы доверяете этому сервису конфиденциальный контент. Многие популярные инструменты отправляют ваш текст на свои серверы для обработки — иногда для аналитики, иногда для обучения ИИ, иногда по причинам, которые не раскрываются явно.

Мы считаем, что это неправильно. Обработка текста — это то, что браузер может прекрасно делать сам, поэтому нет причин отправлять ваши слова на чужой компьютер.

Наши инструменты

WordRoom предлагает семнадцать инструментов:

  • Счётчик слов — подсчёт слов, символов и предложений в реальном времени с корректной обработкой индийских и CJK-письменностей.
  • Преобразователь регистра — тринадцать преобразований регистра, включая правила заглавного регистра AP и Chicago.
  • Проверка читаемости — шесть формул читаемости с обратной связью на уровне предложений.
  • Удаление переносов строк — исправление текста, скопированного из PDF и писем.
  • Сортировка строк — по алфавиту, по длине, в обратном порядке или случайно.
  • Удаление дубликатов строк — поиск и удаление повторов с полным контролем над правилами сравнения.
  • Кодировщик / Декодировщик Base64 — кодирование текста в Base64 или декодирование Base64 обратно в текст.
  • Кодировщик / Декодировщик URL — кодирование или декодирование URL-текста и компонентов строки запроса.
  • Тестер Regex — тестирование регулярных выражений JavaScript против вашего текста в реальном времени.
  • Генератор паролей — генерация надёжных случайных паролей с использованием криптографической случайности.
  • Форматтер JSON — форматирование и красивый вывод JSON с регулируемым отступом.
  • Валидатор JSON — мгновенная проверка синтаксиса JSON с понятными сообщениями об ошибках.
  • Минификатор JSON — сжатие JSON путём удаления ненужных пробелов.
  • Декодировщик JWT — декодирование заголовка и полезной нагрузки JSON Web Tokens локально.
  • Генератор UUID — генерация случайных идентификаторов UUID v4 с использованием криптографической случайности.
  • Генератор хэшей — генерация хэшей SHA-1, SHA-256, SHA-384 и SHA-512 из текста.
  • Генератор слагов — преобразование заголовков в чистые, удобные для URL слаги.

Все инструменты бесплатны, не требуют регистрации и работают в любом современном браузере.
