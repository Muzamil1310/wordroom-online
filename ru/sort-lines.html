Сортировка строк

По алфавиту, по длине, в обратном порядке или случайно — с естественным числовым порядком и локализованной сортировкой.

Алфавитный порядок — это не одна вещь

Сортировка кажется решённой проблемой, пока вы не отсортируете реальные данные. Примитивная сортировка сравнивает кодовые точки, где каждая заглавная буква предшествует каждой строчной — поэтому «Zebra» сортируется перед «apple», а список имён выходит в порядке, который никакой человек не назовёт алфавитным.

Этот инструмент использует локализованное сравнение — тот же механизм, что и ваша операционная система для сортировки списка файлов. Символы с ударениями сортируются рядом с базовыми буквами, а не в конце, а регистр игнорируется по умолчанию, потому что именно это люди подразумевают под алфавитным порядком.

Естественный числовой порядок — другое распространённое удивление. При сравнении как текста «элемент 10» сортируется перед «элементом 2», потому что «1» меньше «2». Естественный порядок сравнивает числовые части как числа, давая элемент 1, элемент 2, элемент 10. Оставьте включённым для чего угодца с числами.

Режимы сортировки

  • По алфавиту — локализованная, без учёта регистра по умолчанию. Включите «По убыванию» для Z к A.
  • По длине строки — короче сначала, равные по алфавиту. Полезно для поиска выбросов в списке ключевых слов или заголовков.
  • Инвертировать текущий порядок — переворачивает список без сортировки, что обычно нужно для хронологического журнала.
  • Перемешать — перемешивание Фишера-Йетса, где каждый порядок одинаково вероятен. Примитивные перемешивания с случайным компаратором предвзяты.

Пустые строки удаляются по умолчанию, потому что отсортированный список с блоком пустых строк на одном конце — редко то, что нужно. Отключите, если пустые строки несут смысл.

Частые вопросы

Почему мой список отсортировался с заглавными буквами в начале?

Это происходит с инструментами, которые сравнивают коды символов, где каждая заглавная буква предшествует строчной. Этот инструмент использует локализованное сравнение и игнорирует регистр по умолчанию, поэтому вы получаете порядок, который ожидает человек. Включите «Учитывать регистр», если нужна строгая версия.

Почему элемент 10 идёт trước элемента 2?

При сравнении как текста «1» меньше «2», поэтому «элемент 10» сортируется первым. Включите «Естественный числовой порядок», чтобы сравнивать числовые части как числа, что даёт элемент 1, элемент 2, элемент 10. По умолчанию включено.

Действительно ли случайный порядок случайный?

Используется перемешивание Фишера-Йетса, где каждый возможный порядок одинаково вероятен. Перемешивание путём передачи случайного компаратора в функцию сортировки — распространённый ярлык, дающий измеримо предвзятые результаты.
