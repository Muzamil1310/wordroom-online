여기가 다른 점

하나의 버퍼, 모든 도구

다른 사이트에서는 모든 페이지에서 텍스트를 다시 붙여야 합니다. 여기서는 텍스트가 여러분과 함께합니다: 다시 붙이지 않고도 세고, 정리하고, 변환하고, 평가하세요. ⌘K를 눌러 기존 텍스트에 변환을 적용하세요.

프라이버시가 제품이지 정책 페이지가 아닙니다

모든 계산이 브라우저에서 이루어집니다. 텍스트를 수신하는 엔드포인트가 없어 유출할 것도, 기록할 것도, 파일 크기 제한도 없습니다. 네트워크 탭을 열고 입력하는 동안 조용히 유지되는 것을 확인하세요.

정확합니다, 대충 정확한 것이 아닙니다

단어 수는 Unicode 세그멘테이션 규칙을 따르므로, 텔루구어, 힌디어, 중국어가 공백으로 분할되지 않고 올바르게 계산됩니다. 제목 대문자는 모든 단어를 대문자로 만들지 않고 실제 AP와 Chicago 규칙을 따릅니다. 학술 모드는 평가자가 제외하는 것을 제외합니다.

키보드를 위해 구축

모든 작업에 키보드 경로가 있습니다. ⌘K로 팔레트를 열고, /로 검색에 포커스하고, ⌘⇧F로 포커스 모드를 활성화합니다. 닫을 수 없는 모달도, 결과 전의 중간 화면도 없습니다.
