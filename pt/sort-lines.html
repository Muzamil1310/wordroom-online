Ordenar linhas

Ordene alfabeticamente, por tamanho, inverta ou embaralhe — com ordenação numérica natural e comparação local.

Alfabético não é uma coisa só

Ordenar parece um problema resolvido até você ordenar dados reais. Uma ordenação simples compara pontos de código, que colocam cada letra maiúscula antes de cada minúscula — então "Zebra" é ordenado antes de "apple", e uma lista de nomes sai em uma ordem que nenhum humano chamaria de alfabética.

Esta ferramenta usa comparação adaptada ao idioma em vez disso, que é a mesma mecânica que seu sistema operacional usa para ordenar uma listagem de arquivos. Caracteres acentuados são ordenados ao lado de suas letras base em vez de no final, e maiúsculas/minúsculas são ignoradas por padrão porque é isso que as pessoas entendem por alfabético.

Ordem numérica natural é a outra surpresa comum. Comparados como texto, "item 10" é ordenado antes de "item 2", porque "1" é menor que "2". A ordenação natural compara as porções numéricas como números, dando item 1, item 2, item 10. Deixe ativo para qualquer coisa com números.

Modos de ordenação

  • Alfabético — adaptado ao idioma, insensível a maiúsculas/minúsculas por padrão. Ative Descendente para Z a A.
  • Por comprimento de linha — menor primeiro, empates resolvidos alfabeticamente. Útil para detectar valores atípicos em uma lista de palavras-chave ou títulos.
  • Inverter ordem atual — inverte a lista sem ordená-la, que é o que você geralmente quer para um registro cronológico.
  • Embaralhar — um embaralhamento Fisher–Yates, então cada ordenação é igualmente provável. Embaralhamentos simples usando um comparador aleatório são enviesados.

Linhas em branco são removidas por padrão, já que uma lista ordenada com um bloco de brancos em uma ponta raramente é o que qualquer pessoa quer. Desative se as linhas em branco carregam significado.

Perguntas frequentes

Por que minha lista foi ordenada com maiúsculas primeiro?

Isso acontece com ferramentas que comparam códigos de caracteres brutos, onde cada letra maiúscula precede cada minúscula. Esta ferramenta usa ordenação local e ignora maiúsculas/minúsculas por padrão, então você obtém a ordenação que uma pessoa esperaria. Ative Sensível a maiúsculas/minúsculas se precisar da versão estrita.

Por que o item 10 vem antes do item 2?

Comparados como texto, "1" é menor que "2", então "item 10" é ordenado primeiro. Ative Ordem numérica natural para comparar as partes numéricas como números, o que dá item 1, item 2, item 10. Está ativado por padrão.

A mistura é realmente aleatória?

Usa uma mistura Fisher-Yates, onde cada ordenação possível é igualmente provável. Misturar passando um comparador aleatório para uma função de ordenação é um atalho comum e produz resultados enviesados mensuráveis.
